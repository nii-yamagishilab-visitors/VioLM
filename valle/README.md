- Original author: Jingjing Tang
- License: [Apache License 2.0](../LICENSES/Apache-2.0.txt)

The associated work is by Jingjing Tang, Xin Wang, Zhe Zhang, Junichi
Yamagishi, Geraint Wiggins, and György Fazekas.

MIDI-VALLE itself adapts Feiteng Li's
[unofficial VALL-E implementation](https://github.com/lifeiteng/vall-e), also
released under
[Apache License 2.0](https://github.com/lifeiteng/vall-e/blob/main/LICENSE).

The VioLM authors modified the upstream code for articulation-aware violin
synthesis, LoRA adaptation, and local runtime support. Original file-level
copyright and attribution notices are retained, and modified upstream files
carry a modification notice.
